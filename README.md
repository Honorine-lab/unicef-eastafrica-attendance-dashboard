## UNICEF East Africa Primary School Attendance Dashboard 2022

**Tools Used:** Power BI, SQL

**Description:**
An interactive dashboard analysing primary school attendance 
rates across Kenya, Tanzania and Uganda broken down by gender, 
using UNICEF 2022 data.

**Key Insights:**
- Kenya had the highest attendance rate
- Female attendance was slightly higher than male across all countries
- Average attendance rate was 80.55%
